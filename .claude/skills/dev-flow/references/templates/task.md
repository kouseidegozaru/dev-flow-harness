## 参照すべき設計

- `docs/04-detailed-design/api/<res>.md` の「<見出し>」 (VAL-..., EC-...)

## テストケース

担当する `test` の ID ごとに 1 つ以上。入力と期待結果を具体的な値で書く。
期待結果が設計の文言・書式そのものなら、写さずに参照してよい (例:「IF-cli-004 の『使い方の表示』の全文」)。
非機能要件 (NFR) の ID は、その「測定条件」(データ量・環境) を前提・入力に書く。
