# 非機能要件

| ID | 区分 | 要件 (数値基準) | 測定条件 | 検証 | 備考 |
|----|------|-----------------|----------|------|------|
| NFR-PERF-001 | 性能 | <例: 1,000 件のとき一覧表示が 200ms 以内> | <環境・データ量> | test | |
| NFR-SEC-001 | セキュリティ | | | test | |
| NFR-AVL-001 | 可用性 | | | manual | <manual の理由> |
| NFR-ENV-001 | 対応環境 | | | test | |
| NFR-OPS-001 | 運用・保守 | | | review | |

性能など数値基準のある項目を `test` にするときは、測定条件 (データ量・環境) を必ず書く。テストはその条件を再現して測り、
タスクのテストケースにも条件を書く (条件を満たさない小さなデータでの 1 回の成功を「達成」としないため)。
テスト環境で条件を再現できない (本番相当の機器・データ量が必要) なら `manual` にし、備考に理由と測り方を書く。
