#### 受け入れ基準

| ID | 受け入れ基準 (Given / When / Then) | 検証 | 備考 |
|----|------------------------------------|------|------|
| REQ-<区分>-001 | Given <前提> / When <操作> / Then `<プログラムが出す値・文言>` と表示する | test | |
| REQ-<区分>-002 | Given ... / When ... / Then `<値>` [DEC-001] で、`!<出てはいけない値>` | test | 境界値。決定: DEC-001 |
| REQ-<区分>-003 | Given ... / When ... / Then `<a>` → `<b>` → `<c>` の順に並ぶ | test | |

Then の中のバッククォートは「受け入れ例の印」(interview-rules.md §10)。承認時に凍結され、受け入れテストの期待値と機械で照合される。
`[DEC-…]` は決定台帳の DEC に依る値、`!値` は「無い」こと、`→` は並び順。Given / When の値と、Then の中のコマンド名には印を付けない。
