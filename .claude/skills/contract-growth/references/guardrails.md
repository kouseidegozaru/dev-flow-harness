# してはいけない施策と、法令の確認

契約数は、ユーザーが納得して契約したときにだけ価値がある。だまして増やした契約は、解約・返金・炎上・行政の処分で戻ってくる。
次のものは **出さない・作らない**。ユーザーに頼まれたときは、理由を伝えて代わりの施策を出す。

## 1. ダークパターン

| してはいけないこと | 代わりにすること |
|--------------------|------------------|
| 実在しない残り時間・残り在庫・「◯人が見ています」の表示 | 本当の期限 (キャンペーンの終了日) だけを示す |
| 解約の手順を契約より難しくする (電話だけ・何画面も引き留める・場所を隠す) | 解約は契約と同じ手軽さで、同じ画面の中で完了できるようにする。引き留めの案は 1 回だけ |
| 有料のオプション・自動更新・メールの受け取りに、最初からチェックを入れておく | 選んだ人だけに付ける |
| 総額・更新後の価格・自動更新を小さく書く、または後から出す | 決済の前に総額・更新日・更新後の価格をはっきり示す |
| 断る選択肢を恥ずかしい文言にする (「いいえ、損してもいいです」) | 「今はしない」など中立の文言 |
| 無料トライアルの終わりを知らせずに課金を始める | 終わりの前に知らせる (levers.md) |

## 2. 法令 (日本でサービスを提供する場合の主なもの)

当てはまりそうなものを施策カードの「法令の確認」に書き、判断が要るものはユーザーに確認する (法律の専門家への確認を勧める)。

| 法令 | 確かめること |
|------|--------------|
| 特定商取引法 (通信販売) | 特定商取引法に基づく表記のページ。**申込みの最終確認画面** に、分量・価格 (総額)・支払いの時期と方法・提供の時期・申込みの撤回と解約の方法・契約期間 (自動更新の条件) を表示しているか。定期購入と誤認させる表示をしていないか |
| 景品表示法 | 「No.1」「業界最安」などの根拠があるか (優良誤認・有利誤認)。通常価格を偽った二重価格表示をしていないか。景品・特典の額が上限の範囲か。**広告であることを隠した口コミ・紹介 (ステルスマーケティング) をしない** |
| 特定電子メール法 | 宣伝のメールは、受け取りに同意した人にだけ送る。送信者の表示と、配信の停止の方法を入れる |
| 個人情報保護法 | 利用目的の範囲で使っているか。計測のために第三者 (解析・広告のツール) に渡す情報は、プライバシーポリシーに書いてあるか |
| 消費者契約法 | 利用規約で、事業者の責任を全部免れる条項・解約に不当な違約金を課す条項を置いていないか |

## 3. 作ってはいけないもの

- 実在しない利用者の声・事例・レビュー・評価、実在しない利用者数
- 他社やその製品をかたる表示、他社のロゴ・名前を許可なく使う比較
- ユーザーの許可なく、連絡先を集めて営業のメールやメッセージを送る仕組み
